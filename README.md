# 🚀 Internet Speed Test (Python)

A simple Python script that measures your **download speed**, **upload speed**, and **ping** using the [`speedtest`](https://pypi.org/project/speedtest-cli/) library.  
It also provides a **rating** based on your download speed.

---

## 📦 Features
- Automatically finds the **best server** for testing.
- Measures:
  - Download speed (Mbps)
  - Upload speed (Mbps)
  - Ping (ms)
- Provides a simple **performance rating**:
  - **EXCELLENT** – 4K streaming + gaming
  - **GOOD** – 1080p streaming
  - **FAIR** – browsing ok
  - **SLOW** – check network

---

## 🛠️ Installation & Usage

### How to run
py speed.py
